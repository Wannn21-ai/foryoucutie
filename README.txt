LITTLE SURPRISE — WEBSITE PDKT

Isi folder:
- index.html
- style.css
- script.js
- assets/ (masukkan foto dan musik milikmu)

PENTING: Tambahkan file milikmu ke folder assets dengan nama:
- photo-1.jpg
- photo-2.jpg
- photo-3.jpg
- music.mp3
- lily-1.png
- lily-2.png
- lily-3.png

Jika nama file berbeda, sesuaikan nama pada index.html atau script.js.

Menjalankan lokal:
1. Buka folder ini di VS Code.
2. Gunakan Live Server untuk membuka index.html.

Deploy tanpa GitHub:
1. Buka https://app.netlify.com/drop
2. Login jika diminta.
3. Upload folder proyek yang berisi index.html dan assets.
4. Salin URL hasil deploy.

Catatan: ZIP ini tidak menyertakan foto atau musik pribadi. Tambahkan sendiri foto dan file musik yang boleh digunakan sebelum deploy.
